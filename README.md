
# Event-Based VIO and SNN-SLAM Research

Research project for developing an event-based visual-inertial
odometry and SLAM pipeline, with eventual SNN and hardware acceleration.

## Research Progression

1. DAVIS event-camera dataset setup
2. Event-based visual odometry
3. VO validation and reproduction
4. MVSEC event + IMU evaluation
5. Visual-inertial odometry
6. Local mapping
7. Loop closure
8. Event-based SLAM
9. SNN formulation
10. Hardware architecture
11. FPGA/SoC implementation

## Datasets

- DAVIS 240C
- MVSEC

Raw datasets are intentionally excluded from Git.
